# WageProof upgrade: implemented changes

24 September 2026. This records delivered functionality against the improvement plan. It does not assign a competition score. Final evaluation, source setup and media acceptance have their own release records.

## The completed product path

Import a record or attributed account → inspect the proposed case → compare it with the last reviewed version → check consequential payment interpretations → retain uncertainty or make an attributed correction → review the selected revision → prepare a factual update with portable evidence. Later records repeat this path within the existing case.

The accepted cobalt design and local Manrope/DM Sans typography are preserved. The interface changes concentrate on comprehension, evidence review and finishing the task.

## What the checks establish

The integrated candidate-4 suite passed **80 tests**, with no failures or skips. Candidate 3 changed comparator tooling while retaining candidate 2's application bytes. Candidate 4 repairs deterministic output selection and adds three export regressions; the interface assets remain identical. Automated checks cover deterministic calculations, state/selection boundaries and controlled recovery. Rendered checks cover named desktop/narrow/keyboard/dialog/export states. Independent agent review found real defects and rechecked the repairs.

The factual update is shorter than the detailed supplement, but has no fixed one-page limit. Four exposed-record outputs under candidate 4 print to three or four A4 pages; retaining changed facts takes priority over a hard truncation. Closed/superseded actions and review/routing actions are outside this active-request selection, and citation-only position changes can remain in the detailed supplement. The interface's full change review and detailed account retain broader context.

Those observations do not establish general document-reading accuracy, representative worker comprehension or agency acceptance. Fresh synthetic model comparisons are reported separately, including incomplete infrastructure attempts and any material failures. Neither quoted source matches nor a successful fictional demonstration are substitutes for that distinction.

## Scope deliberately kept narrow

The build supports a declared ordinary California hourly calculation using supplied premises and English records. It can prepare a factual update with incomplete calculation/routing information. It does not decide entitlement, invent a full balance, contact an employer, file a claim, cover every wage regime or claim offline inference. Image-only PDFs require supplied page images or transcription; mixed PDFs receive bounded labelled OCR.

No worker/practitioner study, measured reduction in human effort or competitive superiority has been established. No new jurisdiction, autonomous filing, public service or decorative agent system was added to manufacture feature count. The recording-ready cut is silent by the user's choice; genuine human narration remains a separate step.

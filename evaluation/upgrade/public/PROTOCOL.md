Ordinary tools may extract/OCR, calculate and retain persistent notes, scripts or a ledger; their use is optional. Do not require app-shaped JSON, needless scripts or a participant-written work log. Automatic event capture supplies audit evidence.

Use a prospective 1,200-second total stage cap, including reconnects and repairs. Record actual token usage/calls when exposed, not invented cost. Different pipelines/tools do not become equal compute merely because model and effort match; call this a matched-model workflow comparison. Do not pool an optional ultra configuration with this baseline.

The baseline workspace contains only released inputs, public task/scope and its own prior artifacts. The native read/write isolation and extraction probes must pass before any execution. Ordinary shell tools use the single native permission profile with no network access. External apps, MCP servers, plugins, browsing, multi-agent delegation, memories, hooks, shell snapshots and image generation are disabled; local image viewing and extraction remain available. The Codex process still uses the user's already configured remote inference provider; this is not offline. Do not treat file-policy checks as protection against every runtime vulnerability or the documented system-temp exception.

## Material scoring gates

Score each key finding pass, material failure, minor issue or unobserved, with saved-output evidence. Correctness includes meaning, not merely literal quotes. Check source completeness, attribution, economic identity, additionality/receipt, gross/net/current/YTD/nonwage types, accounting/rounding, allocation uncertainty, dates/actual work, compound-action supersession, review/history and artifact consistency.

Prospective targets: zero critical user-visible errors; no material discrepancy in completed final artifacts; exact supported integer-cent calculations; supported facts retained with honest unknowns; answered portions retired while remaining questions survive; a new review required for later evidence even with unchanged money. An explicit unreadable-source recovery is not successful interpretation. Blanket abstention is incomplete when supported facts could form a useful update.

Never average away a consequential error with many matching citations. Do not convert files, assertions, output variants or repeated seeds into independent case counts. Synthetic correctness does not certify authenticity, legal accuracy, field benefit, adoption or savings.
